# WP-0.2 — Repository scaffold
**Stage:** 0 · **Depends on:** — · **ADRs:** 001, 002, 010, 011 · **Sessions:** 1

## Goal
A Tauri 2 + React + TypeScript app that builds and runs on macOS and Windows, with the Rust↔TS bridge, lint/test tooling and design tokens in place, so every later WP starts from a green `pnpm check`.

## Scope
- In: scaffold, strict TS, Biome, Vitest, tauri-specta bridge with one command, Paper/Ink tokens, vocabulary check script, `pnpm check`.
- Out: panels/layout (0.5), test corpus and e2e (0.6), CI (0.3).

## Design
- IPC: `app_info() -> AppInfo`.
- UI: single `App` rendering wordmark + info from the bridge.
- Tokens: `src/app/tokens.css`, `[data-mode="ink"]` switch.

## Acceptance criteria
- [x] `pnpm check` green locally (macOS). *(Windows: via CI, WP-0.3)*
- [x] `pnpm tauri dev` opens a window titled "AML" showing version and platform.
- [x] `src/ipc/bindings.ts` is generated by `cargo test` and committed.
- [x] No dependency without a reason: zustand (state, ADR-002), tauri-plugin-log (logs to stdout/file), specta family (ADR-002), Testing Library (component tests).

## Tests
- Unit: `App.test.tsx` (bridge mocked), `commands::app::tests`.
- Rust: `export_bindings_is_current`.
